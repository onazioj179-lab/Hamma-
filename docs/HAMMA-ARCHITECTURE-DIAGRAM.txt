             ↓
    ┌────────────────┐

    └────────┬───────┘
             │
             ↓ For each chunk
    ┌─────────────────────────────────────┐
    │  EnhancedPipeline::process_chunk()  │
    └─────────────────────────────────────┘
             │
             ├─→ 1. Build context
             │     (size, metadata, delta)
             │
             ├─→ 2. For each strategy:
             │     │
             │     ├─→ Check hamma.should_try()?
             │     │   • If mean_gain < threshold → skip
             │     │   • If consecutive_failures > N → skip
             │     │   • Else → try
             │     │
             │     ├─→ Measure start time
             │     ├─→ Apply strategy
             │     ├─→ Measure end time
             │     ├─→ Calculate gain (ratio)
             │     │
             │     └─→ hamma.record(
             │           context,
             │           strategy,
             │           speed_mb_s,
             │           gain
             │         )
             │         • Update mean/stddev (Welford)
             │         • Reset or increment failure count
             │
             ↓
    ┌────────────────┐
    │  Persist State │  pipeline.persist()
    └────────┬───────┘  → hamma.persist()
             │           → Atomic JSON write
             │
             ↓
    ┌────────────────┐

                         THREAD SAFETY MODEL
═══════════════════════════════════════════════════════════════════════════

    Multiple API requests (concurrent)
           │
           ├─→ Request 1: POST /api/compress
           ├─→ Request 2: GET  /api/hamma/stats
           └─→ Request 3: GET  /api/hamma/stats
           │
           ↓
    ┌──────────────────────────────────────┐
    │  StorageService                      │
    │  ┌────────────────────────────────┐  │
    │  │  pipeline: RwLock<Option<>>    │  │ ← Thread-safe
    │  └────────────────────────────────┘  │
    └──────────────────────────────────────┘
           │
           ├─→ Request 1: write().await (exclusive)
           ├─→ Request 2: with_pipeline() (shared read)
           └─→ Request 3: with_pipeline() (shared read)
           │
           ↓ No race conditions
    ┌──────────────────────────────────────┐
    │  Safe concurrent access:             │
    │  • Compress can update pipeline      │
    │  • Multiple reads happen in parallel │
    │  • No data corruption                │
    └──────────────────────────────────────┘
