# Unfinished work

The [HAMMA web backlog](hammer-directive-audit.md#hamma-web-backlog) tracks
release acceptance. See [release readiness](release-readiness.md) for completed
checks. The broader product backlog is below.

1. Expand previews and add persistent workflow
   presets, browser folder change detection, revision history, and workflow
   routes.
2. Extend the processing planner, project concurrency, upload pipelining,
   and progressive bulk downloads. Expand the aggregate job monitor.
3. Build the encrypted recovery vault and scoped temporary sharing. Finish
   encryption-at-rest and public-hosting acceptance.
4. Define and validate the external SDK contract.
5. Choose authorized storage connectors, compute nodes, and object storage
   before implementing privacy-aware hybrid processing, distributed
   coordination, and cost estimation.
6. Build and verify signed platform packages when desktop and native release
   work resumes.
