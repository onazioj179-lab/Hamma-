# Project workflow

Creator: Onazi Treasure Oj.

Make changes on a `codex/` feature branch and open a pull request for the owner
to review and merge. Do not merge your own pull request or push subsequent work
directly to main. Keep the repository scoped to this directory.

Verify builds and behavior relevant to each change. Distinguish JS fallbacks
from native WASM and prototypes from implemented features. Do not advertise
unmeasured throughput or compression guarantees.
